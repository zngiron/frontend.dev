# frontend.dev

Lean Next.js starter template.

## Stack

Next.js (App Router) · React · TypeScript strict · Tailwind CSS 4 · shadcn/ui (Nova) · Biome · Motion · Bun

## Commands

| Command | Does |
|---|---|
| `bun dev` | Dev server |
| `bun run build` | Production build |
| `bun run lint` | Biome check |
| `bun run format` | Biome write |
| `bun run typecheck` | Route typegen + tsc |

## Docs

- `CLAUDE.md` — all project rules (single source of truth)
- `DESIGN.md` — design gate, theming, styling, motion
- `AGENTS.md` — pointer for non-Claude agents
